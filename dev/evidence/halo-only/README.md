# Halo-only verification evidence

This directory records the current halo-only scene after the body and wings
were removed. The moon, reflective floor/water, peripheral debris, particles,
and gold ambient stage remain. The reference media is unchanged and is used to
compare visual atmosphere and hierarchy only; it is not treated as a design
specification for the removed character.

## Reference mapping

The supplied video was reviewed locally for warm halo linework, moving gold
trails, teal atmosphere, and water. Its extracted frames and side-by-side
comparison sheets remain local reference material; this directory publishes
only captures generated by the application. The current scene intentionally
contains no figure or wings.

## Current captures

All current captures were made from the local Vite page
`http://127.0.0.1:5175/angel/` with Chrome DevTools Protocol, after discarding
the first post-navigation surface read and capturing a fresh frame. Desktop
captures use 1440×900 CSS pixels and phone captures use 390×844 CSS pixels,
device scale factor 1.

## Runtime evidence

`runtime-report.json` records the exact URL, viewport, document title, canvas
backing dimensions, scene child visibility, and ring child names for each
check. The report confirms scene children named `moon`, `rings`, `particles`,
`debris`, and `floor`; the ring rig contains `halo`, `trail-waist`, and
`trail-lower`, with no angel or wing object. It also records the manual orbit,
Hero reset, responsive resize, and reduced-motion states.

The final CDP health sample in `runtime-final-health.json` reported no console
exception/log events and no `Network.loadingFailed` requests. `npm run build`
and `git diff --check` pass.
No phone frame-rate or draw-call claim is made; hardware performance was not
measured.
